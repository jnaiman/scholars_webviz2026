# Bolashak Scholars Web Viz Workshop

Source for the workshop website (Jekyll + GitHub Pages): interactive Altair plots on Jekyll pages and Streamlit apps on Streamlit Community Cloud. The site's structure (layouts, per-semester config, slide placeholders) comes from the [PowerBI workshop](https://github.com/jnaiman/scholars_powerbi2026). The content of Modules 1 and 3-5 is adapted from [IS445](https://uiuc-ischool-dataviz.github.io/is445_bcu_fall2026/) (weeks 1 and 8-13) and its PrairieLearn labs.

## Modules

| Module | Topic | Main files |
|---|---|---|
| 1 | Introduction & Setup (browser only: GitHub, Colab, github.io site) | `module01/setup_instructions.md`, `lecture01p0-2.md`, `test_install.ipynb` |
| 2 | Data Viz Basics (unchanged from the PowerBI workshop) | `module02/lecture2p1.md` |
| 3 | Altair plots → JSON → Jekyll site | `module03/lecture3p1-2.md`, `altair_to_json.ipynb`, `jekyll_starter/`, `any_site_starter/` |
| 4 | Streamlit apps on Streamlit Community Cloud (self-contained: account + first deploy in 4.1) | `module04/lecture4p1-3.md`, `streamlit_starter/` |
| 5 | Putting it together & where to go from here | `module05/lecture5p1.md` |
| 6 | *(Optional)* Installing everything locally: Miniconda, git, Ruby/Jekyll, local workflows | `module06/installation_instructions.md`, `lecture6p1-2.md`, `env_files/` |

The workshop itself is **browser only** (Colab + github.com + Streamlit Cloud). Modules 1-3 make one complete tool (a Jekyll site with Altair plots) and Module 4 a second, self-contained one (a Streamlit app), so the workshop can stop after Module 3 if time runs short. Local installs live only in Module 6.

**Starter folders** (`module03/jekyll_starter`, `module04/streamlit_starter`) are files participants copy into *their own* sites/repos. They are excluded from this site's Jekyll build (see `exclude` in `_config.yml`) and linked through GitHub instead. `module03/any_site_starter` *is* built, so its plain-HTML demo page is live on the workshop site.

The two notebooks are generated by scripts in `_tools/` -- edit the script, not the `.ipynb` (see `_tools/README.md`).

## How to install and use locally

1. Clone this repo.
2. [Install Jekyll](https://jekyllrb.com/docs/installation/) (scroll down for OS-specific instructions).
3. `cd` into the repo and run `bundle install`.
4. `bundle exec jekyll serve`, then open the URL it prints (http://localhost:4010/scholars_webviz2026/).
5. Edit text files as needed to update slides, config, course data, etc.
6. Push, and wait for the site to rebuild (see the "Actions" tab on GitHub).

## Set up the workshop for a new semester

1. Make the new repo (e.g. `scholars_webviz2027`) and enable GitHub Pages.
2. In `_config.yml`, update the "CHANGE THESE EVERY SEMESTER" block. `baseurl` is the only place the repo name is written. The workshop URL, GitHub links and Colab links are all built from it.
3. In `_data/class.yml`, update the semester, workshop date/time and room, and the `urls` (MediaSpace channel, IS445 link, CV template, Streamlit starter repo).
4. In lecture slides, use the ALL-CAPS placeholders (`COURSE_WEBPAGE`, `COURSE_COLAB`, `CV_TEMPLATE`, ...) instead of hardcoded URLs. The full list is in the header of `_data/class.yml`.
5. Hard-coded copies of the repo name that can't use the config: the Colab link inside the two notebooks (set `REPO` in the `_tools/` scripts) and the "The Analysis" button in `module03/jekyll_starter/projects/2_my_altair_plots.md`.
6. Work through `update_table.md`.

### Basic Info

This repository is a template for managing coursework using GitHub pages. It
uses the theme [dinky](https://github.com/pages-themes/dinky),
[nbviewer.js](https://github.com/kokes/nbviewer.js), and
[reveal.js](https://revealjs.com/) for presenting material.

Each module is a `moduleZZ` directory with an `index.md` (layout `week`) and lecture slides (`lecture*.md`, layout `lecture`, shown with reveal.js). Resource links go in the `examples:` list of each `index.md`. Besides plain links, these `type:`s build URLs from `_config.yml`: `ipynb` (view in the notebook viewer), `github`, `githubtree`, `githubraw` and `colab` (a path in this repo).
