In this workshop you'll make **interactive plots in Python with Altair**, put them on **your own website** (a Jekyll site on GitHub Pages), and build an **interactive Streamlit app** hosted for free on Streamlit Community Cloud. Everything is done in your web browser, so there is nothing to install. (An optional Module 6 covers installing the tools on your own computer, for after the workshop.)

Below, you will find the materials for each module, as well as the [syllabus](syllabus) that
includes contact information, an outline, and **setup steps to do before the workshop**.
